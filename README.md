📝 To-Do List Application

 📌 Project Overview

The To-Do List Application is a simple Python project developed using Tkinter. It helps users manage their daily tasks by allowing them to add, delete, and clear tasks easily through a graphical user interface (GUI).

 ✨ Features

* Add new tasks
* Delete selected tasks
* Clear all tasks
* Simple and user-friendly interface
* Lightweight and easy to use

 🛠️ Technologies Used

* Python
* Tkinter (GUI Library)

 🚀 How It Works

1. Enter a task in the input field.
2. Click the **Add Task** button to add it to the list.
3. Select a task and click **Delete Task** to remove it.
4. Click **Clear All** to remove all tasks from the list.

 📚 Concepts Used

* Tkinter GUI Components
* Buttons and Labels
* Listbox Widget
* Event Handling
* Python Lists

🎯 Purpose of the Project

This project was created to practice Python GUI development and understand how user interactions are handled in desktop applications.

 📷 Output

The application provides an interactive window where users can manage their tasks efficiently.
